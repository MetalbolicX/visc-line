## For /speckit.specify

**Existing Feature Summary**: Data Services transforms raw data into chart-ready formats — filtering invalid values, computing extents, and creating D3 scales.

**Existing User Scenarios**:
- Raw data array → filter to valid points → create series with data
- Combined extents across multiple series → compute domain for scales
- Scale type (linear/time/log/pow) + domain + dimensions → configured scales

**Edge Cases**:
- All invalid data → empty series, undefined extents
- Log scale with non-positive domain → fallback to linear
- Same data recalculated → use cached extents

## For /speckit.plan

**Implementation Approach**: Pure functions with module-level cache for extents.

## For /speckit.analyze

**Analysis Notes**: Data Services is the core processing engine. Its outputs (scales, processed series) are consumed by all visual components.
