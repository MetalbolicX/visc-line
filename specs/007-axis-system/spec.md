# Feature Specification: Axis System

**Feature Branch**: `007-axis-system` | **Created**: 2026-04-25 | **Status**: Draft

X/Y axis rendering with ticks, labels, and optional axis titles.

**Requirements**: renderXAxis/renderYAxis with D3 axis, renderXAxisLabel/renderYAxisLabel.
**Success Criteria**: Idempotent, time scales format dates, axes outside clip-path.
