## Cross-Feature Awareness

### Dependency Order

Always implement Features in dependency order:
1. First: RG-1 Features (F001, F002, F003, F004)
2. Second: F005 (depends on RG-1)
3. Third: RG-3 Features (F006-F011, depend on F005)
4. Fourth: RG-4 Features (F012, F013, depend on F006)

### Shared Entities

- **Theme** (F001): Consumed by all Features
- **ChartConfig** (F005): Input to all Features
- **ProcessedSeries** (F005): Consumed by F006, F007, F008, F009
- **ChartScales** (F005): Consumed by F006, F007, F008, F009

### Render Pipeline Contract

Charts render via specific sequence — any new renderer must be added to this order:
1. applyThemeCssVars (F001)
2. renderSVG (F003)
3. renderBoundsGroup (F003)
4. renderContentGroup (F003)
5. renderLine (F006)
6. renderPoints (F009)
7. renderTitle (F010)
8. renderXAxis/renderYAxis (F007)
9. renderXGrid/renderYGrid (F008)
10. addTooltip (F012) / addZoomPan (F013)
