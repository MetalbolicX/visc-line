## Core APIs (P1)

### createChart

**Signature**:
```typescript
function createChart<T>(
  container: HTMLElement,
  config: ChartConfig<T>,
  options?: ChartOptions
): ChartInstance<T>
```

**Owner**: Chart Core
**Source File**: `src/chart/createChart.mts`
**Priority**: P1

**Description**: Creates and renders an interactive chart inside a DOM container. Wires up theme CSS variables, renders SVG root and bounds group, prepares internal chart state, and installs resize observer.

**Parameters**:
| Param | Type | Required | Description |
|-------|------|----------|-------------|
| container | HTMLElement | Yes | Host element for the chart's SVG |
| config | ChartConfig<T> | Yes | Chart configuration with data and series |
| options | ChartOptions | No | Rendering options (curve, margins, theme, xType) |

**Returns**: ChartInstance<T> — live chart handle with fluent API

**Throws**:
- Error if container is null
- Error if config.data is not an array
- Error if config.ySeries is empty

**Usage**:
```typescript
const chart = createChart(document.getElementById('root'), {
  data: myData,
  xSerie: { accessor: d => d.date, label: 'Date' },
  ySeries: [{ accessor: d => d.value, label: 'Value' }]
});
chart.withAxes().withTooltip();
```
