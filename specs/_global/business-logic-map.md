## Data Processing Rules

### BL-001: Numeric Data Validation

**Owner**: F005 (Data Services)
**Source File**: `src/services/dataWrangling.mts`

**Rule**: Only values that are valid numbers or Dates are included in processed data.

**Logic**:
```
A value is valid if:
- v !== null
- v !== undefined
- v instanceof Date ? !Number.isNaN(v.getTime()) : !Number.isNaN(Number(v)) && Number.isFinite(Number(v))
```

**Evidence**: `isValidNumber()` function in dataWrangling.mts

---

### BL-002: Series Data Filtering

**Owner**: F005 (Data Services)
**Source File**: `src/services/dataWrangling.mts`

**Rule**: Each series filters data to keep only items where BOTH x and y values are valid.

**Logic**: `rawData.filter(d => isValidNumber(xAccessor(d)) && isValidNumber(yAccessor(d)))`

---

### BL-003: Extent Caching

**Owner**: F005 (Data Services)
**Source File**: `src/services/dataWrangling.mts`

**Rule**: Computed extents are cached using a deterministic key based on series labels and data point values.

**Cache Key Formula**: `${encodeURIComponent(s.label)}:${len}:${front}:${back}`
- front: First 8 chars of first data point stringified
- back: First 8 chars of last data point stringified

**Invalidation**: Cache must be cleared explicitly via `clearExtentCache()` before recomputing with new data.

---

### BL-004: Scale Domain Validation

**Owner**: F005 (Data Services)
**Source File**: `src/services/scales.mts`

**Rule**: Log and power scales require strictly positive domains. Falls back to linear if non-positive values detected.

**Logic**:
```
if (scaleType === "log" || scaleType === "pow"):
  domain must have min > 0 && max > 0
else: always valid
```

## Rendering Rules

### BL-005: Idempotent DOM Rendering

**Owner**: F003 (SVG/Bounds)
**Source File**: All component renderers

**Rule**: All renderers use D3 data join pattern (.data([null]).join()) to ensure exactly one element exists.

**Logic**: `selection.selectAll(element).data([null]).join(elements)` — creates if missing, updates if exists

---

### BL-006: Bounds Group Transform

**Owner**: F002 (Layout)
**Source File**: `src/components/boundsGroup.mts`

**Rule**: Bounds group is translated by (margins.left, margins.top) to create drawing area.

---

### BL-007: Y Scale Inversion

**Owner**: F005 (Data Services)
**Source File**: `src/services/scales.mts`

**Rule**: Y scale range is [innerHeight, 0] (not [0, innerHeight]) to invert Y axis for SVG coordinate system.

**Logic**: `.range([innerHeight, 0])`

---

## Validation Rules

### BL-008: Chart Creation Validation

**Owner**: Chart Core
**Source File**: `src/chart/createChart.mts`

**Rule**: createChart validates inputs before processing.

**Checks**:
- container must be non-null HTMLElement
- config.data must be an array
- config.ySeries must be a non-empty array

---

### BL-009: Disposed Chart Guard

**Owner**: Chart Core
**Source File**: `src/chart/createChart.mts`

**Rule**: Operations on disposed charts throw Error.

**Logic**: `ensureActive()` checks `state.isDisposed` and throws if true.

---

### BL-010: Feature Flag Immutability

**Owner**: Chart Core
**Source File**: `src/chart/chartState.mts`

**Rule**: Feature flags (hasAxes, hasGrid, etc.) drive rendering but consumers should not mutate state directly.

**Access Pattern**: Use `getFeatureFlags(state)` to get a stable snapshot for equality checks.

## Theme/Configuration Rules

### BL-011: Theme Merging

**Owner**: F001 (Theme System)
**Source File**: `src/utils/mergeTheme.mts`

**Rule**: User-provided theme overrides are merged with defaultTheme using DeepPartial semantics.

---

### BL-012: CSS Variable Application

**Owner**: F001 (Theme System)
**Source File**: `src/utils/cssVariables.mts`

**Rule**: CSS variables are applied to container element BEFORE SVG exists.

**Order**: 1. applyThemeCssVars → 2. renderSVG

## Cross-Feature Business Rules

### BL-CF-001: Chart Render Sequence

**Owner**: Chart Core
**Involved Features**: F001, F002, F003, F005, F006-F011

**Rule**: Charts render via specific sequence — skipping or reordering breaks dimensions:

```
1. applyThemeCssVars (F001)
2. renderSVG (F003)
3. renderBoundsGroup (F003)
4. renderContentGroup (F003) — clip-path content layer
5. renderLine (F006)
6. renderPoints (F009) — optional
7. renderTitle (F010) — optional
8. renderXAxis/renderYAxis (F007) — optional
9. renderXAxisLabel/renderYAxisLabel (F007) — optional
10. renderXGrid/renderYGrid (F008) — optional
11. addTooltip (F012) / addZoomPan (F013) — interactivity, applied last
```

---

### BL-CF-002: Resize Re-render

**Owner**: F004 (Accessibility)
**Involved Features**: All Features

**Rule**: Container resize triggers full chart re-render via observeResize callback.
