## §5 Architecture & Strategy

**Domain Profile**: `library` (browser-only component library)
**Interfaces**: `library`
**Concerns**: None
**Framework**: custom (no Foundation — library without framework)

**Architecture Principles Extracted**:
1. **Idempotent Rendering** — All components use D3 data join pattern
2. **CSS Variables First** — Visual styling via `--vl-*` CSS custom properties
3. **Functional Composition** — Small focused functions over component classes
4. **Data Validation Upfront** — Invalid values filtered before rendering
5. **Single Responsibility** — Each module has one clear job
