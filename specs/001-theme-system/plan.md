# Implementation Plan: Theme System

**Branch**: `001-theme-system` | **Date**: 2026-04-25 | **Spec**: `specs/001-theme-system/spec.md`
**Input**: Feature specification from `/specs/001-theme-system/spec.md`

## Summary

Implement the theme system as pure functional TypeScript utilities: merge user overrides with the default theme, apply CSS custom properties to the container, and resolve curve preset strings to D3 factories. No runtime state, no external dependencies beyond D3 types.

## Technical Context

**Language/Version**: TypeScript 5.x (strict mode, ES2024 target)
**Primary Dependencies**: D3.js v7.9.0 (peer dependency — only curve factories used)
**Storage**: N/A (pure functions, no persistence)
**Testing**: Vitest with jsdom environment
**Target Platform**: Browser (DOM required for `applyThemeCssVars`)
**Project Type**: Library
**Performance Goals**: <1ms per operation (pure computation)
**Constraints**: Zero runtime dependencies beyond D3 peer dep
**Scale/Scope**: Micro — 3 exported functions + 1 constant + type exports

## Architecture

### Component Design

```
┌─────────────────────────────────────────┐
│              defaultTheme (constant)      │
│  All styling tokens: axis, colors, grid, │
│  legend, line, points, title, tooltip    │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│         mergeTheme(base, override?)       │
│  Deep merge: override ∪ base defaults    │
│  Arrays replaced (not appended)          │
│  Works with DeepPartial<Theme>           │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│   applyThemeCssVars(container, theme)    │
│  Writes --vl-* CSS custom properties     │
│  on container.style                     │
│  MUST be called BEFORE renderSVG()       │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│   resolveCurve(input) + CURVE_PRESETS    │
│  String → D3 CurveFactory lookup         │
│  Factory pass-through                   │
│  Throws on unknown preset                │
└─────────────────────────────────────────┘
```

### Data Flow

1. User calls `createChart(container, config, { theme: partialOverride })`
2. `mergeTheme(defaultTheme, partialOverride)` → resolved Theme
3. `applyThemeCssVars(container, resolvedTheme)` → CSS vars on container
4. All downstream renderers read CSS vars via `getComputedStyle()`
5. `resolveCurve(curveOption)` → D3 CurveFactory for line rendering (F006)

## Implementation Phases

### Phase 1: Core Theme Merging
- `mergeTheme()` with DeepPartial support
- Type exports: Theme, ThemeOverride, DeepPartial

### Phase 2: CSS Variable Application
- `applyThemeCssVars()` mapping Theme → `--vl-*` CSS vars
- All theme sections mapped (axis, colors, grid, legend, line, points, title, tooltip)

### Phase 3: Curve Resolution
- `CURVE_PRESETS` constant (18 D3 curve factories)
- `resolveCurve()` with validation and friendly error messages
