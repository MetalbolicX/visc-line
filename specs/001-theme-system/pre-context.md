## For /speckit.specify

**Existing Feature Summary**: Theme system provides visual styling configuration via CSS variables and D3 curve presets.

**Existing User Scenarios**:
- User provides custom theme overrides to change colors, fonts, padding
- User selects curve preset to control line interpolation style
- Theme CSS variables are applied to container for CSS-based styling

**Edge Cases**:
- Invalid curve preset string → throws descriptive error
- Partial theme override → DeepPartial merge preserves defaults
- CSS variable prefix collision → uses `--vl-` prefix

## For /speckit.plan

**Implementation Approach**: Pure functional utilities that transform Theme objects and apply CSS variables.

**Key Design Decisions**:
- CSS variables use `--vl-` prefix to avoid collisions
- DeepPartial type allows partial overrides
- Curve presets validated at chart creation time

## For /speckit.analyze

**Analysis Notes**: Theme system is foundational — all other Features depend on CSS variables and curve settings.
