## For /speckit.specify

**Existing Feature Summary**: Layout service calculates drawing dimensions based on container size and margins.

**Existing User Scenarios**:
- Container has defined width/height → calculate inner drawing area
- Margins define space for axes and labels → subtract from total dimensions

**Edge Cases**:
- Container with zero dimensions → handle gracefully
- Negative margins → validation error

## For /speckit.plan

**Implementation Approach**: Pure calculation function from container dimensions and margins.

## For /speckit.analyze

**Analysis Notes**: Layout is foundational — its outputs (width, height, margins) are consumed by scales, SVG, and all components.
