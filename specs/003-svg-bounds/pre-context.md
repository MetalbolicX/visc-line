## For /speckit.specify

**Existing Feature Summary**: SVG/Bounds provides the SVG container hierarchy — root SVG, bounds group, and content group with clip-path.

**Existing User Scenarios**:
- Create SVG element sized to container → render bounds group → render content group
- Clip content to inner drawing area → axes render outside clip region
- Apply ARIA label for accessibility

**Edge Cases**:
- Re-render when container resizes → update SVG dimensions
- Multiple calls → idempotent (no duplicate elements)

## For /speckit.plan

**Implementation Approach**: D3 data join pattern ensures idempotent rendering.
